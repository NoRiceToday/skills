# Lesson template

One concept per lesson. Copy this shape and replace the angle-bracket parts.

```markdown
## Konzept
<The idea in plain language, before any code.>

## Code
<What it is and where it lives: agent, tool, instruction provider, callback, workflow.>

```<lang>
<snippet>
```

## Erkennung
The cue that identifies <pattern> in code:
- <cue 1>
- <cue 2>

## Warum
<What breaks or what it costs.>

## Idiomatisch
```<lang>
<corrected snippet>
```
<One line: why the fix avoids the consequence.>

## Repo
<file:line in the codebase under study>
```

Then close with the teach-back: ask the learner to explain <concept> in their own words. A filled example for a given codebase lives with that material, not here.
