# Learner profile

Update this per learner and per session. It sets the depth of every lesson.

| Field | Value |
| --- | --- |
| Expertise | <field-level strength> |
| Knows | <concepts already solid> |
| New to | <the tool or codebase being taught> |
| Wants | <tool surface, architecture judgement, hands-on, ...> |
| Pace | <one concept per message, fast, ...> |
| Language | <language for delivered lessons> |

## Example

| Field | Value |
| --- | --- |
| Expertise | Strong in AI and agent concepts |
| Knows | Agents, tools, state, evals in general |
| New to | Google ADK (API surface) |
| Wants | Read and judge generated ADK code, not type it |
| Pace | One concept, explained fully, no pre-quiz |
| Language | German |
